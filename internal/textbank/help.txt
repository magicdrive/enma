Usage: enma [SUBCOMMAND] [OPTIONS]

Description:
   Yet another event-driven command runner.

General options:
  -h, --help                          Show help message and exit.
  -v, --version                       Show version.
  -c, --config                        Specify enma.toml (optional. default: ./Enma.toml, ./.enma.toml, ./.enma/enma.toml, ./.config/enma.toml)

Sub commands:
  init                                Create plain enma.toml, .enmaignore file.
  hotload                             It detects file changes and builds and loads the daemon.
  watch                               Detects file changes and executes commands.
  scheduler                           Runs commands on cron schedules.
  config validate                     Check a config file without running it.


init options:
  -h, --help                           Show help message and exit.
  -m --mode <hotload|watch|scheduler|enmaignore> Specify mode of the configuration file to be created. (optional. :default: hotload)
  -f, --file-name <filename>           Specify filename of config file to be created. (optional. default: ./Enma.toml|.enmaignore)

hotload options:
  -h, --help                           Show help message and exit.
  -d, --daemon <command>               Defines the daemon command. (required)
  -b, --build <command>                Defines the command to build daemon. (required)
  -S, --signal <signal>                Define signal to stop the daemon command. (optional. default: SIGTERM)
  --start-at-once <command>            Defines the command run once at startup, before the first build. (optional)
  -W, --working-dir <dir_name>         Defines working directory. (optional. default: $PWD)
  -w, --watch-dir <dir_name>           Specify watch directories. Allows comma separated list. (optional. default: the working directory)
  -p, --pre-build <command>            Defines the command to pre-build daemon. (optional)
  -P, --post-build <command>           Defines the command to post-build daemon. (optional)
  -I, --placeholder <placeholder>      Defines placeholder replaced with path where event in command. (optional. default: "{}")
  -s, --args-path-style <style>        Defines filepath-style where event in command. (optional. default: "dir,base,ext")
  -B, --build-at-start <on|off>        Run a build before starting daemon for the first time. (optional. default: "on")
  -C, --check-content-diff <on|off>    Fires only when the file contents are changed. (optional. default: on)
  -A, --abs, --absolute-path <on|off>  File name passed to placeholder must be an absolute path.  (optional. default: on)
  -t, --timeout <time>                 Specify the build command timeout. (optional. default: '5sec')
  -l, --delay <time>                   Specify delay time after the build command. (optional. default: '0sec')
  -r, --retry <number>                 Specify retry count. (optional. default: '0')
  -x, --pattern-regex <regxp>          Specify watch file pattern regexp. (optional.)
  -i, --include-ext <extension>        Specify watch file extension. Allows comma separated list. (optional.)
  -g, --ignore-file-regex <regexp>     Specify watch file ignore pattern regexp. (optional.)
  -G, --ignore-dir-regex <regexp>      Specify watch dir ignore pattern regexp. (optional.)
  -e, --exclude-ext <extension>        Specify watch exclude file extension. Allows comma separated list. (optional.)
  -E, --exclude-dir <dir_name>         Specify watch exclude dir_name. Allows comma separated list. (optional.)
  -D, --default-ignores <max|min|none> Defines default loads enmaignore volume. (optional. default: minimal)
  -n, --enmaignore <path>              Defines enmaignore path. Allows comma separated list. (optional. default: ./.enmaignore)
  --logs <log_file_path>               Specify enma log file. (optional.)
  --pid <pid_file_path>                Specify enma pid file. (optional.)

watch options:
  -h, --help                           Show help message and exit.
  -c, --command --cmd <command>        Defines the command to execute when file change event. (required)
  -W, --working-dir <dir_name>         Defines working directory. (optional. default: $PWD)
  -w, --watch-dir <dir_name>           Specify watch directories. Allows comma separated list. (optional. default: the working directory)
  --start-at-once <command>            Defines the command run once at startup, before file monitoring starts. (optional)
  -p, --pre-cmd, --pre-command <command>  Defines the command to pre-execute cmd. (optional.)
  -P, --post-cmd, --post-command <command> Defines the command to post-execute cmd. (optional)
  -I, --placeholder <placeholder>      Defines placeholder replaced with path where event in command. (optional. default: "{}")
  -s, --args-path-style <style>        Defines filepath-style where event in command. (optional. default: "dir,base,ext")
  -C, --check-content-diff <on|off>    Fires only when the file contents are changed. (optional. default: on)
  -A, --abs, --absolute-path <on|off>  File name passed to placeholder must be an absolute path.  (optional. default: on)
  -t, --timeout <time>                 Specify the cmd command timeout. (optional. default: '5sec')
  -l, --delay <time>                   Specify delay time after the build command. (optional. default: '0sec')
  -r, --retry <number>                 Specify retry count. (optional. default: '0')
  -x, --pattern-regex <regxp>          Specify watch file pattern regexp. (optional.)
  -i, --include-ext <extension>        Specify watch file extension. Allows comma separated list. (optional.)
  -g, --ignore-file-regex <regexp>     Specify watch file ignore pattern regexp. (optional.)
  -G, --ignore-dir-regex <regexp>      Specify watch dir ignore pattern regexp. (optional.)
  -e, --exclude-ext <extension>        Specify watch exclude file extension. Allows comma separated list. (optional.)
  -E, --exclude-dir <dir_name>         Specify watch exclude dir_name. Allows comma separated list. (optional.)
  -D, --default-ignores <max|min|none> Defines default loads enmaignore volume. (optional. default: minimal)
  -n, --enmaignore <path>              Defines enmaignore path. Allows comma separated list. (optional. default: ./.enmaignore)
  --logs <log_file_path>               Specify enma log file. (optional.)
  --pid <pid_file_path>                Specify enma pid file. (optional.)

scheduler options (one job; use a config file for several jobs):
  -h, --help                           Show help message and exit.
  --cron <expression>                  6-field cron: "second minute hour day-of-month month day-of-week". Sunday is 0. (required)
  --command <command>                  Defines the command to run with sh -c. (required)
  --name <name>                        Job name shown in the logs. (optional. default: default)
  --working-dir <dir_name>             Working directory of the command. (optional. default: $PWD)
  --timezone <zone>                    Time zone of the cron expression. (optional. default: OS local time)
  --timeout <time>                     Time limit of one attempt. (optional. default: none)
  --retries <number>                   Retries after a failed attempt. (optional. default: 0)
  --retry-delay <time>                 Wait between a failed attempt and its retry. (optional. default: 10s)
  --max-concurrent <number>            Maximum attempts running at once. (optional. default: 4)
  --next <number>                      List the next N fire times of the job and exit; nothing runs. (optional. at most 100)
  --logs <log_file_path>               Specify enma log file. (optional.)
  --pid <pid_file_path>                Specify enma pid file. (optional.)

config validate options:
  -h, --help                           Show help message and exit.
  -c, -f, --config <file>              Config file to check. (optional. default: the file a plain `enma` would run)
  --next <number>                      Scheduler configs: list the next N fire times of each job. (optional. at most 100)
