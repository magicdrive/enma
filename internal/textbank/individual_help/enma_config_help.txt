Usage: enma config validate [OPTIONS]

Check a config file the way `enma` would load it, without running anything:
no command is started and no pid or log file is written.
Problems are reported per check, each line naming the file: all problems of one check
together; a later check runs once the earlier ones pass.
Exit code: 0 valid, 1 invalid, 2 unknown flag.

Options:
  -c, -f, --config <file>               Config file to check.
                                        Optional. Default: the file a plain `enma` would run
                                        (Enma.toml, .enma.toml, .enma/enma.toml, .config/enma.toml)

  --next <number>                       Scheduler configs: list the next N fire times of each job,
                                        computed like the scheduler does (time zone, DST).
                                        Optional. Default: 0 (none). At most 100.

  -h, --help                            Show help message and exit.
